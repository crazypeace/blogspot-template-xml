# blogspot-template-xml
Blogger/blogspot template xml 极简模板

## Blogger/blogspot 导入模板文件时, 系统会强行将 Followers widget 里面的 title 设置为 h2
如果想全盘规划 h1, h2, ... 标签的模板, 那么就不要使用 关注者 小工具 Followers widget  
https://zelikk.blogspot.com/2026/08/blogger-blogspot-followers-widget-title-auto-h2.html

## Blogger/blogspot 的 举报滥用情况 小工具 ReportAbuse widget 系统会固定输出 h3 标签
如果想全盘规划 h1, h2, ... 标签的模板, 那么就不要使用 举报滥用情况 小工具 ReportAbuse widget
https://zelikk.blogspot.com/2026/08/blogger-blogspot-reportabuse-widget-h3.html

## Blogger/blogspot 的 博客搜索 小工具 BlogSearch widget 不能设置标题为空
如果不希望页面显示 博客搜索 小工具 的标题, 只能通过CSS隐藏的方式.
https://zelikk.blogspot.com/2026/08/blogger-blogspot-blogsearch-widget-title-null.html
